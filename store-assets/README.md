# Chrome Web Store assets

The editable HTML/CSS source is in `source/`. Render the upload-ready PNG files with:

```sh
node store-assets/render.mjs
```

Generated files are written to `store-assets/output/` at the exact Chrome Web Store dimensions:

- `promo-small-440x280.png`
- `promo-marquee-1400x560.png`
- `screenshot-global-1280x800.png`
- `screenshot-zh-CN-1280x800.png`
